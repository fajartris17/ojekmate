# OjekMate — Aplikasi Pendamping Mitra Ojol & Taksi Online

Aplikasi pendukung kerja driver **motor (ojek online)** dan **mobil (taksi online)** seperti Gojek, Grab, Maxim, inDrive, dan Bluebird.

Bukan pengganti aplikasi platform. Ini catatan pribadi: order, penghasilan bersih, target, BBM, dan perawatan kendaraan.

**Repo:** https://github.com/fajartris17/ojekmate

## Fitur
- Dashboard order, omzet, bersih, dan target harian
- Catat trip motor atau mobil (platform, tarif, tip, km, komisi)
- Kalkulator bersih setelah komisi 8% + BBM + tol/parkir
- Log oli, servis, ban, checklist siap kerja
- Catatan pengeluaran (BBM, makan, tol, pulsa)
- Backup data JSON, jalan offline (PWA)

## Cara pakai di HP
1. Buka `index.html` di Chrome, atau aktifkan GitHub Pages.
2. Titik tiga ⋮ → **Tambahkan ke layar utama**.
3. Ikon OjekMate muncul seperti aplikasi biasa.

### Aktifkan GitHub Pages
1. Buka repo ini → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder `/ (root)`
4. URL biasanya: `https://fajartris17.github.io/ojekmate/`

## Cara jadi APK Android
1. Aktifkan GitHub Pages.
2. Buka [pwabuilder.com](https://www.pwabuilder.com/).
3. Masukkan URL Pages → Package for stores → Android.
